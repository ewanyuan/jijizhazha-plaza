Qwen Office 积分延迟结算可能造成透支

多位群友报告千问办公积分扣减有延迟：任务运行期间显示的消耗不完整，之后可能补扣，甚至出现负积分。有使用者称让 Qwen 3.8 Max 写研究报告花近 5000 分仍未完成，而 DeepSeek 完成类似任务据称只花约 50 分但质量较低；另有人做脚本核对账目，报告欠 3669 分。数值是个别用户报告，积分兑换成本与任务质量不可直接外推。

这是实际成本和产品计费体验，提醒长任务、子代理及高档模型可能导致账单延迟显现。

运行长任务前后查看积分明细，留意「透支扣减」并给高消耗任务设预算上限。

编程 Agent 体验对比：Trae、CodeBuddy、WorkBuddy 与 QoderWork

一位群友认为 Trae 在国内编程 Agent 中的 harness 较强，并称 Codex 当时响应慢、Claude 使用门槛高；另一位称 CodeBuddy 完成最快但正确率低，且有用户反馈同模型同任务下 WorkBuddy 产出更好。也有人认为 QoderWork 可与 WorkBuddy 相比，另有群友表示千问办公好用但不能切换模型、积分消耗重。评价来自个人任务，结论不应视为普遍排名。
