实践经验2026-10-15 09:50值得读

Grok Bot 接 Claude Code 有账号封禁风险，网络出口变化是一个案例原因

群友转述一例：两台电脑的网络环境不同，Grok Bot 云电脑出口随当前网络变化；切到国内网络后，Claude Code 报 403，Bot 多次重试后账号被封。另一位群友也报告在 Grok Bot 中登录后立即被封；同时有人称自己按手机订阅、再在 Grok Bot 使用的方式暂时未被封。群内反馈不一致，封禁规则未明。

这是可能造成订阅或账号损失的实际踩坑信息，也提示重试与网络出口变化可能带来风险。

若尝试此类接入，先核对 Bot 实际网络出口，避免在不确定环境下让任务自动反复重试。
